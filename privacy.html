Privacy Policy

Last updated: 24 November 2026

Day Agent (Google Cloud project bs-dashboard-bot) is a personal assistant used only by its developer, Bexruz Hoshimov. It is not available to other users.

Google data the app accesses

  • Google Calendar: reads and creates events (e.g. class schedule, meetings).
  • Google Tasks: reads and updates task lists to keep them in sync with the bot.
  • Gmail (read-only): reads new messages to send the owner short notifications.
  • Google Drive (file metadata only): searches file names; file contents are not read.
  • Google Sheets: writes the owner's own expense spreadsheet.
  • YouTube (read-only): reads subscriptions and liked videos for recommendations.

How the data is used and stored

Data is used only to show information to the owner in a private Telegram chat. OAuth tokens and app data are stored on the owner's private server. Short text snippets may be sent to an AI model (Google Gemini) to understand the owner's messages.

Data is not sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further data collection.
